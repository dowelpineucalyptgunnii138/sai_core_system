Most computers purchased within the last five years meet these needs. If your machine is older, the system may run slower.

## ❓ Frequently Asked Questions

**Does the system collect my data?**
The system processes data locally on your computer. It does not send your files or personal information to any cloud servers.

**Do I need an internet connection?**
You only need an internet connection to download and install the software. You can use all core features offline.

**How do I update the system?**
When you open the app, it checks for updates. If a newer version exists, a window appears with a link to download the change.

**Can I stop a process once it starts?**
Yes. Click the Cancel button in the middle of any active task to stop the current action immediately.

**Where do my finished files go?**
By default, the system saves results in a folder labeled "SaiResults" inside your Documents directory. You can change this location in the Settings menu.

## 🔧 Troubleshooting

If you run into issues, try these steps first:

*   **Restart the app**: Close the window and open it again.
*   **Check for updates**: Ensure you run the latest version from the GitHub link.
*   **Check disk space**: If the system stops mid-task, verify that you have space left on your hard drive.
*   **Administrator rights**: If the installer fails, right-click the file and select Run as Administrator.

The system uses a log file to track errors. If a problem persists, open the log file in the Settings menu and look for the red text. This text describes what caused the issue. You can copy this text to help you search for solutions online.

## 🔒 Security Practices

The sai_core_system uses local processing. This means your data stays on your hard drive. We prioritize privacy by avoiding external tracking modules. The installer contains a digital signature to verify that it comes from the correct source. If Windows presents a security warning during installation, click More Info and then click Run Anyway to proceed. This warning occurs for new files not yet recognized by your system.
